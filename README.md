## Selected work

### SteelMade — product discovery for a furniture brand

**System:** production website with responsive product discovery and enquiry flows.

- Live site: [steelmade.co.in](https://steelmade.co.in/)
- Public implementation: [steelmade-cloudiary](https://github.com/element-bendr/steelmade-cloudiary)
- Focus: clear catalogue navigation, mobile usability, and a direct path from product exploration to enquiry.

### ChronoQuill — reviewed WhatsApp publishing automation

**System:** local-first, deterministic publishing automation built around TypeScript, SQLite, Baileys, CLI operations, and review controls.

- Public implementation: [chronoquill](https://github.com/element-bendr/chronoquill)
- Focus: predictable publishing operations instead of opaque, one-off automation.

### AI operating memory — governed context for coding agents

**System:** a governed memory pattern for AI-assisted engineering: Git-reviewed knowledge, retrieval, pgvector projections, and Beads-backed workflows.

- Private implementation; architecture and working approach available in a consulting conversation.
- Focus: make agent context durable, inspectable, and reviewable rather than relying on fragile chat history.

### Multi-site institutional publishing

**System:** three public institutional sites with a private admin application for staff-managed content.

- Private implementation; source and client material are not published.
- Focus: reduce the operational burden of managing multiple sites while keeping publishing controlled.

### Content operations workflow

**System:** deterministic Instagram content planning with bounded caption generation, validation, manifests, and daily briefs.

- Private implementation; source and client material are not published.
- Focus: turn recurring content planning into a repeatable workflow with review points.
