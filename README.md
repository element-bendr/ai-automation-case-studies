## Cloudflare Daily News Intelligence Agent — newsharness

- **System:** Cloudflare-native daily news intelligence system.
- **Problem solved:** Daily intelligence workflows often become untraceable AI summaries. This system makes collection, source tracking, provider observability, clustering, extraction, drafts, publishing, and reporting inspectable.
- **What it does:** Runs scheduled news intelligence workflows using Cloudflare Agents SDK, Durable Objects, D1, R2, modular collection providers, provider observability, story clustering, extraction, enrichments, article drafts, public publishing, weekly synthesis, and content refresh checks.
- **What this proves:** Cloudflare Agents SDK, Durable Objects, D1/R2 architecture, AI workflow automation, provider observability, evals, run traces, and inspectable AI reporting.
- **Status:** Built MVP / Cloudflare-native intelligence system.
- **Public/private note:** The repository is private. This public case study is sanitized; source can be discussed in a technical walkthrough where appropriate.

## AI Coding-Agent Memory System — memory-os

- **System:** Governed memory operating system for AI coding agents.
- **Problem solved:** AI coding agents lose context, repeat mistakes, and mix temporary task state with durable knowledge.
- **What it does:** Uses Git-reviewed Markdown as canonical truth, GBrain retrieval, Postgres/pgvector projections, Beads task state, agent skills, evidence/date/source/owner rules, setup/verify/sync/backup/restore workflows, and verification-gated handoffs.
- **What this proves:** AI-assisted engineering operations, memory governance, Postgres/pgvector usage, agent workflow architecture, and evidence-based automation discipline.
- **Status:** Built internal AI coding-agent memory system.

## ChronoQuill — WhatsApp publishing automation
